# Sicherheit

Keine Tokens, Zugangsdaten, privaten Geräteschlüssel oder ungeprüften vollständigen
Diagnosen in öffentliche Issues aufnehmen.
Nach Veröffentlichung die private GitHub-Sicherheitsmeldung verwenden, sofern
sie vom Maintainer aktiviert wurde. Andernfalls zunächst ohne sensible Details
nach einem privaten Meldeweg fragen.
Das lokale Entwicklungspaket hat keine garantierten Wartungsfristen.
